# Measured Code Constraints

## Problem and Outcome

Owns comparable measurements, routine and container policy, the refactoring-safe ratchet, ownership attribution and the code CLI. Clone detection belongs to clone-constraints; locality and vocabulary-backed data rules belong to code-locality-data; CLI conventions and execution evidence are consumed contracts.

## Boundary Candidates

- CodeFacts: Versioned observations, provenance, completeness and identity.
- CodeConfig: Limits, reasons, scopes, provider policy and config digest.
- CodeLimits: Routine/container limits and highest measurements.
- CodeRatchet: Eligibility, match trust, decomposition and net accounting.
- CodeAttribution: Existing join adaptation and task selection.
- CodeEvaluate: Pure evaluation order and extension report composition.
- CodeReport: Canonical findings, hints and coverage contribution types.
- CodeFeedback: Effective-rules block and idempotent splice.
- NativeMeasure: Native measurement crate and adopted dependency pins.
- GitBefore: Revision, rename/deletion manifest and before blobs.
- CodeCommands: Code command definitions and I/O orchestration.
- CodeTests: Pinned hand-counted metric corpus and provider comparison.
- CodeDocs: Definitions, limits, blind spots, baseline and adoption procedure.

## Upstream / Downstream

- Upstream: cli-contracts, verification-evidence.
- Downstream: clone-constraints, code-locality-data.
- Acceptance: the named deliverables in design.md, each exercised through its own journey and current evidence.
